How to use this board

  • Write your own main. One call per row, print the result, compare it with the expected column.
  • Part 1 means the libc behavior, literally. Same prototype, same results as the man page. The only deviations are the ones the subject sets: is* functions return exactly 1 or 0 (glibc returns other non-zero values), and ft_calloc follows the subject's rule for size 0.
  • Compile test mains with -fno-builtin. Otherwise the compiler folds libc calls on literals (memcmp("abc","abz",3) becomes -1 instead of -23) and you compare your function with the compiler, not with libc. Use runtime strings (strdup) when you want to be sure.
  • Guard bytes. Put sentinel bytes before and after every buffer you write into, so an out-of-range write shows up.
  • Sanitizers. cc -Wall -Wextra -Werror -g -fsanitize=address,undefined, free every allocated result, and skip undefined behavior (NULL into libc, overlapping memcpy).
  • Parts 4 and 5 are commands to run and things to check, not C calls. The Makefile rows assume a clean checkout, in order.
  • Edge rows are the ones that usually break a first attempt. Tick state is saved in this browser only.
